## Resource ownership increment

- Added execution handles for runtime/proxy resources. Stop closes admission immediately, drains every handle, attempts both resources even after a failure, deduplicates concurrent close calls and retains failed handles for retry.
- Controller step cleanup, final cleanup and Stop use this registry. Current execution still remains sequential.
- Manual permission tickets capture originating runtime, native request ID and task ID. Colliding native IDs receive distinct tickets; duplicate events do not add duplicate requests. Replies update the owning task rather than whichever task is currently selected.
- Proxy startup checks closure before and after asynchronous startup, preventing a stopped proxy from reopening its listener.
- Validation includes two-lane drain barriers, failed containment and retry at registry and Controller levels, colliding permission IDs and proxy startup cancellation. These are synthetic runtime fixtures; simultaneous real model execution is not claimed.
