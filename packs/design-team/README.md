# Design Team

The Lead coordinates the UX Designer, UI Designer, and Independent Design Reviewer. Skills cover journeys, interface specs, design tokens, accessibility, handoffs, and structured verdicts.

Import and publish `ux-design` in the project. It takes `brief` (confirmed Markdown) and optional `briefArtifactId` (a project artifact ID). The Lead waits for explicit confirmation before starting it.

The flow reviews the user journey, then specifies screen states and tokens and checks accessibility. It allows one spec revision. A passing spec reaches operator sign-off; the output includes the spec and outstanding checks for a rendered implementation. The flow does not implement the interface.
