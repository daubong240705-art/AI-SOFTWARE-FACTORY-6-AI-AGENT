# Evidence-based delivery

Read the task goal and acceptance criteria. Search existing project knowledge before gathering new material. Record the sources and versions used, state assumptions, and distinguish verified conclusions from uncertainty.

Write a deliverable that answers the assigned question. Check each acceptance criterion, register the file with the Host, and give a concise handoff that identifies decisions and remaining questions.
