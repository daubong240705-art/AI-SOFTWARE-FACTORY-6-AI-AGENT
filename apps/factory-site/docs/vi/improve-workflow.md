## Đọc bằng chứng từ run

Mở **Hiệu quả** (Insights) của workflow, xem những run có lỗi, thời gian chờ hoặc chi phí bất thường. Đối chiếu Trace để phân biệt lỗi node, runtime và input.

## Từ Insights đến Draft

Yêu cầu đề xuất cải tiến dựa trên run. Xem diff và lý do trước khi áp dụng vào Draft. Kiểm lại port, input và cổng duyệt; chạy thử trước khi Publish version mới.

> Đề xuất không tự Publish và không sửa version mà các run trước đang dùng.
