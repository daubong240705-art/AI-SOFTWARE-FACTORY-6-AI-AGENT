## Tạo hồ sơ

1. Mở dự án → **Agent & Team** và tạo agent, hoặc bắt đầu bằng Agent template.
2. Đặt vai trò, hướng dẫn, runtime và model khi runtime yêu cầu. Nêu rõ đầu ra, tiêu chí nghiệm thu và lúc phải dừng.
3. Gắn skill cần thiết, cấp quyền tool tối thiểu và đặt ngân sách.
4. Thêm agent vào team; nếu cần phản biện độc lập, khai báo quan hệ `reviews` cho agent phù hợp.

## Kiểm tra cấu hình

Thử một task nhỏ hoặc dùng agent trong Draft workflow rồi chạy thử. Kiểm tra task, attempt và tool call trong Trace trước khi mở rộng phạm vi.
