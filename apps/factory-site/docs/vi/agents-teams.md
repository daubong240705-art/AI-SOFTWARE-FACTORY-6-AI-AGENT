## Agent là dữ liệu của dự án

Hồ sơ agent chứa vai trò, hướng dẫn, model, runtime, skill, tool và ngân sách. Các runtime gồm API agent, OpenCode trong sandbox bubblewrap và adapter CLI cục bộ tùy chọn như Claude Code hoặc Codex CLI.

## Quan hệ điều phối

Team nhóm agent theo nhiệm vụ. Đồ thị tổ chức có `manages`, `reviews`, `collaborates` và `approves` để định tuyến, phối hợp và phản biện. Quan hệ không vượt qua chính sách tool hoặc cổng phê duyệt. Có thể tạo team từ Thư viện hoặc yêu cầu Lead đề xuất cấu hình.
