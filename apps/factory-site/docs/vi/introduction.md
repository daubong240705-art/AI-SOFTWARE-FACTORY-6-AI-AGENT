Factory điều phối đội AI trên máy của bạn. Bạn trao đổi với Lead, xác nhận phương án, rồi theo dõi workflow và duyệt ở những bước cần người quyết định.

## Factory gồm những gì?

Host quản lý trạng thái bằng SQLite, kiểm tra lệnh và điều phối runtime. Giao diện web đọc trạng thái và sự kiện từ Host. Agent làm task qua runtime đã cấu hình; task sửa mã có thể dùng Git worktree riêng.
