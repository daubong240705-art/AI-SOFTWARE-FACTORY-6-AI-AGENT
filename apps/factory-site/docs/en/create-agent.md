## Create a profile

1. Open **Agents & Teams** in your project and create an agent, or start from an agent template.
2. Set the role, instructions, runtime, and model if the runtime requires one. Specify the expected output, acceptance criteria, and when to stop.
3. Attach the required skills, grant only the tool permissions the agent needs, and set a budget.
4. Add the agent to the team. If you need an independent review, define a `reviews` relationship for the appropriate agent.

## Check the configuration

Try a small task or add the agent to a draft workflow and run a test. Check the task, attempt, and tool calls in Trace before expanding the scope.
