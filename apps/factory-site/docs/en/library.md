## Reusable building blocks

Skills guide specific work. Agent, team, and workflow templates provide starting points. Work already created can retain its pinned inputs.

## Packs

Packs bundle reusable templates and skills. The software pack includes `software-delivery` and `bug-fix`, the research pack provides `research-report`, and the architecture and design packs have specialized flows. Import a flow into a project and publish it before asking the Lead to run it.
