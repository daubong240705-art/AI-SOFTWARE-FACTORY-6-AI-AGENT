## Create your first project

1. [Install Factory](./install.md) and sign in. If the Host shows a one-time bootstrap token, use it locally to establish your session.
2. Create an empty project or choose a team template. Attach a local Git repo if agents will edit code.
3. Open **Agents & Teams** and confirm the Lead, roles, and runtimes are configured.

## Test without a model

In **Workflow**, create or import a draft. Save it, choose **Test run**, enable **Mock agents**, and enter the required inputs. Start with a workflow that does not write to external systems. Follow node progress in **Monitor**.

## Give the Lead a goal

Once a model is configured, open Lead chat and describe the outcome. Discuss the options, confirm a specific plan in your own words, then check the decision brief and run. Review pending approvals in **Needs attention**.
