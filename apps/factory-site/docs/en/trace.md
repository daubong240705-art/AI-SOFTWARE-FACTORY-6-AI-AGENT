## Follow a run

Monitor shows current workflow progress, including nodes that are running or waiting. Trace connects request → run → node → task → attempt → tool call → artifact. Follow those links when investigating a failure or gathering evidence for approval.

## Inspect costs and improvements

Inspect usage by node and agent. Unknown cost is not zero. Insights can suggest changes based on run evidence; apply them to a draft for review and testing, then publish manually when ready.
