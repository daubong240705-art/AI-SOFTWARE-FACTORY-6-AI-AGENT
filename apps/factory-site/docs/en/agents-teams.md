## Agents are project data

Agent profiles define role, instructions, runtime, model, skills, tools, and budget. Runtimes include API agents, OpenCode in a bubblewrap sandbox, and opt-in local CLI adapters such as Claude Code and Codex CLI.

## Teams and relations

Teams group roles. The relations `manages`, `reviews`, `collaborates`, and `approves` help route work and review. They do not override policy or approval gates. Start with a team template or ask the Lead to propose a setup.
