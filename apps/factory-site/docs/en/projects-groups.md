## Projects own the work

A project holds agents, teams, tasks, workflows, and artifacts. Attach a Git repository for code work; code-producing attempts can work in separate worktrees instead of editing your checkout.

## Groups organize projects

Groups can nest up to five levels, share a library and budgets, and pass defaults down to projects. Verify effective settings in the project before running work; some defaults can be overridden at a narrower scope.
