## Start a run

Select a published workflow in your project and choose **Run**, or confirm a plan in Lead chat so the Lead can start the appropriate workflow. Provide inputs of the expected types, check the version, and track progress in Monitor.

## Handle an approval request

Open the request in **Needs attention** and check the scope of the action and any referenced artifact or commit. Approve it if everything checks out, or reject it if there are unresolved issues. After deciding, check the next node and result in Trace. If the outcome of an external action is unclear, verify it against the target system before choosing **Retry**.
