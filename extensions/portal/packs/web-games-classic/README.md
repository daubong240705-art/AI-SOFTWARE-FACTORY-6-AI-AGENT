# Web Games (cũ)

Bản mẫu cũ từ `v2-games-final`: Lead, Game Designer, Rules Engineer, UI Artist, Client Engineer và QA Engineer. Giữ quy trình cố định `workflows/game-build.json` (v1) cùng bộ hồ sơ và kỹ năng ban đầu. Mở workflow theo quy trình nhập/chuyển đổi v1 của Host; không trông chờ lệnh chat cũ tự khởi chạy.

Pack này không tự publish. Để phát hành, chạy `game-publish` của pack Web Games mới với tích hợp Portal trong dự án, hoặc dùng action `bundle.publish` sau khi người vận hành duyệt. Không dùng module publish cũ.
