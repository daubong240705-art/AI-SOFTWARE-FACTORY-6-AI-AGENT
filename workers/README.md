Phase 2 control-plane jobs use `python -m workers.dispatcher` (DB outbox → RQ JSON queue) and `python -m workers.main` (single Linux RQ worker). `jobs.py` fences delivery/generation and holds a PostgreSQL advisory lock during graph/checkpoint writes. Heartbeat lease expiry permits bounded recovery; completed artifacts are reused on resume. No Docker socket, repository checkout or coding CLI is used here. The remote coding-worker protocol and sandbox in `infrastructure/worker/` belong to Phase 5.
