# Bàn giao V1.2A

Ngày 04/11/2026. Baseline `fcfac1d`, nhánh `feature/windows-worker-v1.2a`, phiên bản `1.2.0-alpha.1`. [Kế hoạch V1.2](../plan/v1.2/README.md).

## Đã triển khai

- Tab **Workspace** trong panel chat: tạo workspace riêng từ Git HEAD sạch, xem đường dẫn/baseline, mở thành project, kiểm tra phục hồi và dọn có xác nhận.
- Worktree detached, locked bằng ID ngẫu nhiên, nằm dưới userData/workspaces. Project con trong monorepo giữ scope thư mục con; index/workdir tách với source gốc. Không tự commit/stash/reset, không copy dependency hoặc secret từ source gốc.
- Atomic manifest ghi trước tạo và sau kết quả. Controller kiểm tra ownership trước runtime, lưu `workspaceOrigin` vào run/export. Source local thông thường tiếp tục chạy như cũ; vẫn một run/task tuần tự.
- Recovery kiểm tra Git registration/lock/common-dir, `.git` marker/backlink, đường dẫn canonical và junction; giữ dữ liệu khi không xác minh được. Trường hợp gián đoạn sau unlock có thể nhận lại lock bằng thao tác phục hồi; không nhận foreign lock. Manifest tạo dở nhưng không có tree/registration có thể dọn riêng metadata.
- Cleanup token một lần, 60 giây, kiểm tra lại lúc xóa. Chặn file sửa/new/ignored, commit mới hoặc branch, project/history reference, foreign lock/metadata hoặc đường dẫn bị thay. Kiểm tra tất cả run trong SQLite, không chỉ 50 lượt gần nhất. Không tự xóa worktree có kết quả; không force-remove hoặc prune worktree bên ngoài.
- Git manager tắt hooks bằng thư mục riêng trống, loại Git environment override, chặn submodule và filter áp dụng lên source trước checkout/status. Không thực thi script từ repo tham khảo hoặc thêm dependency/framework.

## Cách dùng và giới hạn

Đóng bản cũ, vào `apps/windows-worker`, chạy `npm start`. Chọn project Git sạch → mở panel → **Workspace → Tạo workspace riêng → Mở làm dự án**. Gửi yêu cầu trên project mới để làm việc cách ly. Muốn quay lại chọn project gốc ở sidebar; kết quả worktree vẫn giữ.

V1.2A chưa tự gộp thay đổi về project gốc, chưa thực thi hai agent đồng thời. Dependencies cần chuẩn bị riêng trong worktree; file ignored cũng khiến cleanup bị chặn. Muốn dọn project đã mở phải bỏ khỏi danh sách và không còn lịch sử/reference; không xóa history để ép dọn khi còn kết quả cần giữ. Worktree còn sửa hoặc commit mới được giữ đến bước tích hợp V1.2C hoặc xử lý Git có chủ đích.

Manifest lỗi/foreign bị bỏ qua khi liệt kê và không được nhận/xóa tự động. Nếu repository di chuyển/mất metadata, giữ folder để xử lý thủ công. Git worktree dùng chung object database/config với repo gốc: đây là cô lập file/index phục vụ lập trình, không phải OS sandbox. Repo có submodule/filter hiện báo chưa hỗ trợ.

Schema SQLite vẫn v6; optional origin không phá lịch sử. Rollback ứng dụng cần dừng mọi run/local command; giữ nguyên thư mục workspaces và metadata Git, không xóa userData. Phiên bản cũ không có UI quản lý worktree mới. Chưa phát hành installer WW-5 theo yêu cầu.
