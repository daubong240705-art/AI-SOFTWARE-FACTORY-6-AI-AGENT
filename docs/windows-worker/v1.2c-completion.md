# V1.2C — tích hợp và kiểm thử source hợp nhất

Phiên bản `1.2.0-alpha.3`, baseline `0b3b32a`, checkpoint `checkpoint/v12c-20261104`, nhánh `feature/windows-worker-v1.2c`. Phần triển khai đã có; nghiệm thu model thật và benchmark hoàn chỉnh **chưa đạt**, nên chưa chốt V1.2 stable.

**Cập nhật kế tiếp:** [Lead review alpha.4](review-quality-completion.md) đã hoàn tất nghiệm thu mẫu với DeepSeek Flash cho cả tuần tự và song song. Các số liệu và giới hạn bên dưới mô tả riêng thời điểm alpha.3.

## Thay đổi

- Một worktree tích hợp riêng, cùng HEAD gốc với task; không commit, merge hay ghi vào source gốc. Mỗi dependency/fix/review nhận worktree mới đã chứa các kết quả tích hợp trước đó.
- Gộp ba chiều theo toàn bộ file: baseline của task, kết quả task và bản tích hợp hiện tại. Cùng nội dung thì không ghi lại; hai nội dung khác baseline trên cùng file tạo conflict, kể cả sửa khác dòng. Preflight toàn bộ tập file trước khi ghi.
- Chỉ dùng byte snapshot đã lưu và kiểm tra hash. Kiểm tra scope, ownership, HEAD detached, alias, symlink/junction, hardlink và file đặc biệt. Giữ bản dự phòng trước khi ghi. Hủy/lỗi I/O có thể để lại một phần đã áp dụng trong worktree riêng; trạng thái conflict giữ dữ liệu và không tự replay.
- Scheduler vẫn tối đa hai execution và một Controller. Dependency chỉ được nhận sau tích hợp; TEST đợi mọi task sửa code. Sau fix, chạy lại task bị ảnh hưởng và TEST trên source mới. Request/deadline/process ownership giữ theo V1.2B.
- Review đối chiếu trên source hợp nhất. Catalog loại command ref của source cũ; file ref còn được kiểm tra theo hash và task. Chỉ hoàn tất khi mọi AC có bằng chứng hợp lệ và có TEST thành công trên đúng source cuối cùng.
- Giao diện hiển thị trạng thái tích hợp, version, conflict và **Mở bản tích hợp**. Xem từng file bằng snapshot bất biến. Source gốc vẫn có diff riêng.
- Hàng chờ giữ lại sau lượt tích hợp; retry/recovery không phát lại vào source gốc. Mở bản tích hợp làm project để tiếp tục bằng tuần tự hoặc một agent. Chưa tạo worktree cô lập lồng trong owned workspace.
- History/export giữ origin, baseline và snapshot tích hợp/task; cleanup bảo vệ worktree còn tham chiếu. Không đổi schema SQLite.
- Runtime nhận diện `finish=length` và báo giới hạn output 8.192 token, kể cả khi còn text một phần. Không tự tăng hạn mức, đổi model hay retry.

## Kiểm chứng

Git thật trong fixture kiểm tra thêm/sửa/xóa, file tên `constructor`/`__proto__`, seed dependency, chạy đồng thời và test lại sau fix, conflict không ghi một phần trong preflight, source gốc/index nguyên vẹn, output bị sửa muộn, ownership drift, junction, hủy giữa các file và chặn replay. Bộ kiểm tra evidence bao gồm command cũ bị loại nhưng file hash hợp lệ được giữ.

Giao diện Electron thật qua IPC đã xem được task output bất biến, nhãn chờ xác minh, worktree được giữ và mở bản tích hợp làm project. Ảnh đã kiểm tra trực tiếp; fixture UI không gọi model hay thay production database. Tóm tắt tại [v1.2c/ui.json](v1.2c/ui.json).

DeepSeek Flash `ds/deepseek-v4-flash` qua 9Router/OpenCode 1.19.5 đã thực hiện hai bản sửa độc lập, tích hợp và chạy TEST trên source hợp nhất trong bốn lượt. Chạy lại hai Node test độc lập ngoài agent đều pass; source/index gốc giữ nguyên. Nhưng review cuối chưa nghiệm thu: hai lượt bị từ chối do refs sai/cũ; hai lượt trả rỗng. Metadata lượt cuối ghi `finish=length`, `output=0`, `reasoning=8192`. Chỉ đọc metadata kết thúc, không xuất nội dung reasoning.

Một lượt tuần tự với cùng fixture cũng sửa đúng và test pass nhưng review bị chặn bởi evidence. Quan sát song song 80,6–121,3 giây, 17–21 request; tuần tự 108,9 giây, 20 request. Đây là các lượt review không thành công, prompt đã thay đổi giữa các lần và model có biến thiên: **không phải benchmark hợp lệ, không chứng minh tăng tốc**. [Quan sát đã rút gọn](v1.2c/live-observations.json) không chứa prompt, key hoặc reasoning.

Kiểm tra cuối: **125/125 test**, typecheck, production build, Prettier, Git diff check và native Electron/SQLite/secure storage đều đạt; chi tiết tại [checks.json](v1.2c/checks.json). Full cache/runtime/fixture vẫn trong `.cache/asf-research/` bị Git bỏ qua; production SQLite chỉ được đọc settings và credential qua safeStorage khi chạy live, không chỉnh sửa.

## Còn lại trước V1.2 stable

1. Giảm kích thước/độ lặp của context và output review; kiểm soát output/reasoning theo capability model mà không âm thầm tăng chi phí. Nghiệm thu lại với DeepSeek Flash để đạt review có refs đúng và JSON hoàn chỉnh.
2. Chạy các cặp tuần tự/song song tương đương, cùng cấu hình và prompt đã cố định, báo throughput gồm cả tích hợp/test/review trên các lượt hoàn tất.
3. Chưa tự giải conflict theo dòng, gộp vào branch gốc hay cài dependency từ source gốc. Người dùng xử lý conflict trong worktree và quyết định đưa kết quả vào repo.

Giữ Factory Lite + Windows Worker; WW-5 installer tiếp tục bỏ qua. Scope/Full access là policy của ứng dụng, không phải OS sandbox; agent shell vẫn có quyền tài khoản Windows.
