# V1.3A — Agent Monitor 2D

Ngày bàn giao: 04/11/2026. Phiên bản `1.3.0-alpha.1`. Nhánh `feature/windows-worker-v1.3a`, baseline `2b5326f`, checkpoint `checkpoint/v13a-start-20261104`.

## Kết quả

Màn **Đội ngũ** hiển thị Lead và sáu role với khả dụng độc lập: Rảnh, Đang làm, Đã tắt, Chưa cấu hình. Execution đang chạy có task, model snapshot thực tế, thời lượng, hoạt động đọc/sửa/chạy lệnh/kiểm thử/chờ model/chờ quyền/dừng. Hai execution cùng role giữ identity riêng; queued dependency không làm role giả thành bận. Khi xem project khác run đang chạy, có thông báo đúng phạm vi.

Chat có nút mở Đội ngũ; monitor và chip Chat dùng cùng một poller snapshot theo project. Snapshot có epoch/revision và trả unchanged nhẹ, không đưa settings/credential/output lớn vào payload. Khi request lỗi hoặc treo quá ngưỡng, giữ dữ liệu lần cuối kèm “Chưa đồng bộ”, không biến agent thành rảnh. Đổi project không nhận nhầm dữ liệu.

Tiến độ hiển thị task và tiêu chí đã xác minh trong **run hiện tại/gần nhất của project**, không phải tổng tiến độ mọi backlog của project. Chỉ có final run + review V2 verified + gate tích hợp tương ứng mới được tính verified; task đã thực thi xong trước review vẫn chưa tăng số verified. Fix/retry cùng logical task không đếm trùng. Run direct có thể đã kết thúc nhưng chưa có acceptance verification, nên không cộng verified.

## Dữ liệu và lifecycle

- Observation lưu theo task/direct execution: UUID, timestamp, model requests đang chờ, tool calls đang mở/đã kết thúc. Tool end chỉ đóng đúng call; late start/reconciliation không dựng lại hoạt động đã kết thúc.
- Controller ghi event metadata có version, taskId/executionId/activity. Permission và Stop ưu tiên đúng activity. Không lưu reasoning/raw text stream vào monitor.
- ModelProxy thông báo khi request upstream đóng để kết thúc “Chờ model”; không thay endpoint/model, retry, request budget hoặc quyền runtime.
- Snapshot revision dựa nội dung projection, không phụ thuộc số event; vẫn đổi khi log đã chạm cap 2.000. Log legacy vẫn đọc được. Timeline đầy đủ/coalescing là C.
- Query run gần nhất theo project trực tiếp trong SQLite, không tìm trong danh sách toàn cục 50 run.
- SQLite schema **6 → 7**: thêm metadata nullable và hai bảng nền `board_items`/`board_links`. Chưa có API CRUD/board UI; thuộc B. Migration transaction, DB6 có backup bằng `VACUUM INTO` tại `worker.schema6.pre-monitor.backup.sqlite`, giữ chat/draft/run/evidence/ciphertext.
- App cũ chặn schema mới. Muốn rollback: đóng app, giữ riêng dữ liệu mới, phục hồi backup có chủ đích; không tự downgrade DB hoặc xóa dữ liệu.

## Giới hạn và tiếp theo

V1.3A hoàn thành A-01–06 trong phạm vi trạng thái/bảng 2D và schema nền. B–E chưa triển khai. Kanban CRUD, timeline theo agent, inspector dùng chung, 3D, low GPU và benchmark nằm ở các đợt tương ứng.

Chat vẫn có polling chi tiết lịch sử hiện có; mới có monitor snapshot và chip dùng chung, chưa thay toàn bộ cache runDetail của Chat (C-04). UI hiện cho biết loại hoạt động và tiêu đề task; chi tiết đường dẫn file/lệnh xem qua kết quả hiện có, chưa có inspector mới. Thời gian chờ là quan sát hoạt động, chưa có báo cáo thời lượng phân rã hay ETA.

Giữ một run hoạt động toàn ứng dụng, tối đa hai task theo chế độ isolated-pair; Full access/gate evidence/worktree ownership không thay. Không thêm orchestrator, VM, OpenProject/GitLab Server hay installer WW-5. File roadmap do người dùng cung cấp giữ nguyên và không đưa vào commit.
