# Windows Worker V1.1

Ngày hoàn thiện: 04/11/2026. Branch `feature/windows-worker-v1.1`, baseline `2d632d8`, tag dự phòng `checkpoint/v11-20261104`. Phiên bản ứng dụng `1.1.0`.

V1.1 hoàn thành phạm vi [đã chốt](../archive/plan/v1.1/VERSION_SCOPE.md): tăng độ ổn định của Worker hiện có, một Controller, một run, task tuần tự. Không thay VM, gateway, credentials hoặc source bên ngoài workspace.

## Thay đổi người dùng nhận được

- Giữ phản hồi/đề xuất Lead khi source đổi đồng thời. Run báo `workspace-changed`, không gán nguồn sửa cho agent và không thực thi plan trên baseline cũ. Snapshot thiếu có đường dẫn/lý do riêng, bao gồm file khóa và file quá lớn.
- Checkpoint trước run, trước/sau task, sau TEST và sau run; lưu hash source, Git HEAD/index/root. Giữ tối đa 40 checkpoint/run, tái sử dụng evidence trước/sau và rollback từng file có sẵn. Không tự commit/stash/reset project.
- Mở lại app giữ lịch sử và đánh dấu interrupted, xóa quyền đang chờ. **Kết quả → Kiểm tra để tiếp tục** kiểm tra source/Git và job cũ. Token một lần, hết hạn 60 giây; source đổi hoặc snapshot thiếu sẽ chặn. Tiếp tục bằng run/session mới có `retryOf`/`recoveryOf` và context hữu hạn; không reattach session hay tự replay lệnh. Có thể kết thúc lượt gián đoạn, giữ source/kết quả.
- Windows Job Object quản lý runtime và npm/test/dev server con. Child suspended được gắn job trước ResumeThread; EOF lifetime pipe và kill-on-close dừng cây tiến trình. Random job identity dùng cho recovery, không kill/adopt theo PID lịch sử. Hủy trong lúc spawn bất đồng bộ phải chờ host đóng; lock không được thả nếu chưa xác minh dừng.
- **Chạy local** chọn npm script trong project, chỉ một lệnh local, start/stop/output giới hạn 64.000 ký tự có redaction. URL loopback trong log có nút preview, không tự mở LAN/trình duyệt. Có thể giữ server khi agent chạy; dừng lệnh trước restore/recovery. Khi đóng app có lựa chọn tiếp tục làm hoặc dừng rồi đóng.
- Export JSON theo run với task/model/checkpoint/command/metrics và event còn lưu. Che giá trị credential trong từng chuỗi trước serialize; không export settings/credential/profile instructions/context/reasoning. Timeline kỹ thuật có tìm kiếm, lọc loại sự kiện, sequence ID; sự kiện Controller mới có task ID trong text, run ID là trace chung. UI xem 300 event gần nhất; export toàn bộ tối đa 2.000 event đã lưu/run.
- Dọn lịch sử có preview/token, bảo vệ active/interrupted/queue, attempt/context references và blob còn được dùng. Giao diện mặc định hơn 30 ngày và giữ 20 lượt mới nhất. Không xóa source hoặc runtime cache OpenCode; không tuyên bố SQLite thu nhỏ file vật lý ngay sau xóa.

## Đối chiếu roadmap

| Mục | Kết quả |
|---|---|
| STAB-01 | Tái sử dụng SQLite schema6/run/task/session/model/settings snapshot; thêm checkpoint và recovery refs optional, không migration phá dữ liệu |
| STAB-02/03 | Source/Git checkpoint, inspect/continue bằng attempt mới, abort, evidence/restore giữ nguyên thay đổi có sẵn |
| STAB-04 | Tái sử dụng deadline/request/fix bounds, failure taxonomy và proxy latch; không thêm tầng retry task hoặc replay tool. Lỗi gateway dừng có chủ đích thay vì tự backoff/replay |
| STAB-05/06 | Metrics có nguồn/unknown, context/handoff/skills hữu hạn có sẵn; context recovery tối đa 14.000 ký tự. Cost vẫn unknown, không suy đoán giá/billing |
| STAB-07 | Windows Job Object + owned manifest, Stop, startup cancel, parent/host crash và local server lifecycle |
| STAB-08 | Trace bằng run ID, event sequence/task text, lọc timeline và export; không đổi schema event hoặc thêm hệ thống tracing |
| STAB-09 | Fault injection proxy 401/429/503/network/budget có sẵn; bổ sung file lock, startup cancellation, process crash, source drift, recovery và UI thật |

Phần ownership/recovery của AU-4B và phần local preview/lifecycle/export/retention của WW-4D được bàn giao trong V1.1. Installer WW-5, panel resize nâng cao và benchmark so sánh hiệu năng AU-5 vẫn là đầu việc riêng.

## Dùng và rollback

Đóng cửa sổ bản cũ, trong `apps/windows-worker` chạy `npm start`. Mã helper C# nằm trong checkout và được PowerShell 5.1 Add-Type biên dịch khi chạy; chính sách máy chặn helper sẽ báo lỗi. Shell vẫn chạy bằng tài khoản Windows, không phải OS sandbox. Không cần cấu hình thêm backend.

Schema vẫn v6. Dừng run/local command trước khi đổi bản; sao lưu userData nếu cần. Phiên bản cũ đọc được các field JSON optional nhưng không có chức năng V1.1; không xóa DB hoặc runtime metadata để ép rollback. Retention xóa lịch sử sau thao tác rõ ràng và không thể hoàn tác bằng Git. [Chi tiết dữ liệu/rollback](../archive/plan/v1.1/MIGRATION_AND_ROLLBACK.md).
